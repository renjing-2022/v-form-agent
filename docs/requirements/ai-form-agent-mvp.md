## 1. 背景与问题

当前 `v-form` 设计器右侧已嵌入 AI 聊天面板，但实现方式为前端直连 Dify / Coze：

- 密钥暴露在浏览器侧，存在安全风险；
- 对话结果未形成可应用的 v-form JSON 闭环；
- 无法稳定支撑“按业务规范生成合规表单”的交付目标。

业务侧需要在低代码设计器中，通过自然语言或上传评估类 Excel，自动生成可在画布上直接查看与继续编辑的表单。

## 2. 目标

在本仓库 `agent/` 内建设本地智能体服务，替换前端直连外部 AI 平台的主路径，实现：

1. 用户用自然语言描述业务需求，生成整张 v-form 表单；
2. 用户上传评估量表类 Excel（优先），解析后生成整张表单；
3. 生成结果符合 v-form 组件规范（`widgetList` + `formConfig`，`jsonVersion: 3`）；
4. 用户确认后一键应用到设计器画布，可继续拖拽微调。

## 3. 非目标（MVP 不做）

- 对话式增量修改当前表单；
- PDF / Word / 图片 OCR 导入；
- 复杂事件脚本、数据源、自定义 CSS 自动生成；
- 小计 / 总分自动计算公式落地；
- 生产级独立部署与多租户；
- 继续以 Coze / Dify 作为主生成链路（可保留旁路，但不作为验收主路径）。

## 4. 用户与场景

### 4.1 目标用户

表单设计人员、业务配置人员（如康养评估表配置）。

### 4.2 核心场景

| 编号 | 场景 | 成功标准 |
|---|---|---|
| S1 | 自然语言整表生成 | 输入需求描述后得到可预览的合规 formJson，确认后画布展示对应控件 |
| S2 | Excel 评估量表整表生成 | 上传类似「老年人认知能力专项评估」结构的 xlsx，生成分区 + 评分题目（单选）表单 |
| S3 | 结果确认与应用 | 校验失败不写画布；校验通过后 `loadFormJson` 成功刷新设计器 |

## 5. 功能需求

### FR-1 本地 Agent 服务

- 在 `agent/` 提供可与前端同机运行的 HTTP 服务；
- DeepSeek 云 API Key 仅保存在服务端环境变量；
- 前端通过 Vite 代理访问 Agent，不再在浏览器直连 DeepSeek / Coze / Dify 作为主路径。

### FR-2 自然语言整表生成

- 输入：中文业务描述；
- 输出：`{ formJson, summary, warnings[] }`；
- 生成布局以单列或简单分组为主，优先保证合规性与可渲染性。

### FR-3 Excel 评估量表导入（优先格式）

输入 Excel 特征（以现有样例为准）：

- 存在分区标题（如「认知评估」「感知觉与沟通」）；
- 题目与评分标准同区展示；
- 评分说明常位于合并单元格的多行文本（如 `4分：...` / `0分：...`）；
- 可能含 Logo、水印、已填分值、「小计」「总分」。

处理要求：

- 抽取「分区 → 题目 → 选项(分值+文案)」结构；
- 忽略 Logo / 水印 / 已填答分；
- 「小计 / 总分」可降级为只读说明或占位，不要求首期实现计算逻辑；
- 无法可靠识别的内容进入 `warnings`，不得导致服务崩溃。

### FR-4 合规 JSON 与画布回填

- formJson 必须可被现有设计器 `loadFormJson` 加载；
- 组件类型限制在白名单内（MVP 建议：`input`、`textarea`、`radio`、`select`、`number`、`date`、`static-text`、`divider`、简单 `grid`）；
- 评估量表题目默认映射为 `radio`（选项 value 为分值，label 为标准文案）；
- 前端提供「预览 / 警告提示 / 应用到画布」交互，禁止静默覆盖。

### FR-5 可运维基础能力

- 请求可中断或超时失败有明确错误信息；
- 上传文件限制类型（`.xlsx` / `.xls`）与大小；
- 开发期同机启动说明可写入仓库文档。

## 6. 验收标准（产品层）

1. 同机启动 `v-form` 与 `agent` 后，AI 面板可完成至少一次自然语言整表生成并应用到画布。
2. 使用「老年人认知能力专项评估」类 Excel 样例，可生成包含分区标题与若干评分单选题的表单，并成功应用到画布。
3. 故意上传损坏文件或非法 JSON 时，界面有错误提示且画布不被破坏。
4. 浏览器网络面板中，主生成请求指向本地 Agent 代理路径，而非 Coze / Dify 主域名。
5. DeepSeek API Key 不出现在前端打包产物与前端源码默认值中。

## 7. 约束与假设

- 模型：DeepSeek 云 API；
- 文档：首期仅 Excel；
- 能力：首期仅整表生成；
- 部署：开发阶段 Agent 与前端同机；
- 规范真源：`v-form/src/components/form-designer/widget-panel/widgetsConfig.js` 与 `getDefaultFormConfig()`。

## 8. 风险

- 评估量表 Excel 合并单元格与版式差异大，解析召回不稳定；
- 模型可能输出白名单外组件类型；
- 复杂嵌套布局一次生成失败率高，需通过“字段计划 + 代码组装”降低风险。

## 9. 里程碑建议

| 阶段 | 交付 |
|---|---|
| M1 | Agent 骨架 + DeepSeek 调用 + 文本生成闭环 |
| M2 | Excel 量表解析 + 黄金样例通过 |
| M3 | 前端确认回填、错误提示、替换直连主路径 |
