# v0.5.0 — Truth Strict 全量收敛 + Refine 删/排/复制

## 概述

v0.5.0 将 Catalog applicable 键全面收敛为 **strict + valueKind**，并补齐与手动设计器对齐的结构操作：按 label 删除、同级重排、复制控件（含 tab-pane 级联删除）。

## 主要能力

### Truth Strict（A2）

- 全 applicable 键写入 `valueKind` + `strict: true`
- `catalog:check` full strict sweep（`catalog-full-strict-sweep`）
- known-gap 报告（`editorGaps`）不阻塞 sweep；`defaultValue` 等例外按策略跳过

### Refine 结构 op

- `removeField` / `removeFieldsInScope`：按目标删除；删除 tab-pane 时子控件一并移除（不提升）
- `reorderField`：同级 first/last/before/after
- `duplicateField`：deepClone + 递归新 id/name（对齐 designer 复制语义）
- 删后公式悬空 warning；table / data-table 等 NON_GOAL 拒绝
- IntentGate：结构 op 全失败或歧义 → 422；诚实 summary 含 `structure=*`

### 前端 / 安全

- 前端无 DeepSeek 密钥（`frontend-no-secret`）
- v0.4 labelAlign 等回归用例保留
