# v0.8.0 — 交互执行面第二刀：受约束事件 JS + 真实渲染 applied

## 概述

v0.8.0 在 v0.7 EventSpec / `/event` 澄清基线上增加 **受限事件 JS 生成、静态护栏、真实 VFormRender 预览验证闸与合入**：只有在预览中按 examples 真实执行、且服务端以 `actual` 对照 `expect` 重判全部一致时，才允许写入画布。

本版交付范围收窄为 **事件安全写入与真实执行闸 + 少量模板交互**；任意自然语言页面交互（如 tab 下一页 + 校验 + 失败定位）属 v0.9。

## 主要能力

### `/event` 状态机

- `clarify` → `spec_ready`
- `generate` → `code_preview`（候选 JSON，不写原画布）
- `apply` → `applied` / `draft`（无全绿报告或 actual≠expect 则 draft）

### 约束生成与护栏

- 按 eventKey 分派模板：值变更求和/显隐禁用、按钮/生命周期/子表增行字面量、`onFormValidate` 规则编译
- AST 护栏拒绝网络、动态执行、DOM、定时器、未知字段

### 真实预览闸

- AiChat「在预览中验证」复用设计器 appContext 挂载真实 VFormRender
- 报告只含可观察状态；服务端重判 `actual` vs `expect`
- Playwright 9 条真实触发用例 + AiChat 全链路 / 负例
