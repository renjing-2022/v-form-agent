# v0.6.0 — 重型容器第一刀：data-table 扁平列 + sub-form + vf-dialog 壳层

## 概述

v0.6.0 在 v0.5 Truth Strict + 字段结构 op 基线上，开放重型容器**可验收子集**：既有 data-table 扁平列增删排改、既有 sub-form 子字段结构 / 壳层属性、既有 vf-dialog 壳层属性；不可新建这些 type；不做事件、多级表头、reparent，不扩 create 白名单。

## 主要能力

### data-table 扁平列

- 专用列 op：增列 / 删列 / 同级重排 / 改列字段（label、prop、width 等）
- 多级表头 → reject；禁止经 `updateField(tableColumns)` 整段替换

### sub-form

- 子字段 `remove` / `reorder` / `duplicate`；`addField` 进入既有 sub-form（白名单 type only）
- 壳层属性 refine（如 showBlankRow 等，按 container 矩阵）

### vf-dialog

- 壳层属性 refine（title / width 等）
- 事件链仍 forbid；dialog 内字段沿用 v0.5 结构 op

### 边界保持

- **不可新建** data-table / sub-form / vf-dialog
- grid-sub-form / vf-drawer 仍 NON_GOAL
- create 白名单不变
