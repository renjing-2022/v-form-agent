# v0.9.0 — 自然语言直出交互 JS：模型写代码与场景 → 真实执行 → 自动修正 → 确认写入

## 概述

v0.9.0 将 AiChat 统一到 `/interaction`：自然语言经 DeepSeek **直接写出**结构变更、事件 JS 与验证场景；在真实 VFormRender 预览中执行，失败自动修正（≤2 轮）；用户确认后结构与事件同一事务写入画布。本管线静态护栏只禁网络请求。

相对 v0.8：**Breaking** — 不再提供「生成交互代码」等旧 `/event` UI；按钮文案为「发送」；纯结构经 `route_refine` → `/refine`。

## 主要能力

### `/interaction` 管线

- `generate` → 模型输出 handlers JS + scenarios（契约校验）
- 真实预览执行 scenarios → 服务端重判 verificationReport
- `repair`（场景指纹 + 上限）→ `apply`（伪造/缺报 → draft；全绿 → applied）
- 结构 + 事件同一事务；失败整单不写

### 统一入口与分流

- AiChat 统一走 `/interaction`
- 纯结构意图 `route_refine` → `/refine`
- mock 无匹配 fixture：交互类诚实失败；明确结构/禁网/澄清可本地意图回退

### 题库与回归

- PRD 题库正例：fixture generate → **真实预览**跑 scenarios → apply → 独立断言
- 冒烟：真实 Key，证据不含 Key
- v0.8 / v0.7 / v0.6 可跑子集回归；旧 `/event` UI e2e 以 `test.skip` 记录 Breaking

## 升级说明

1. 拉取 `v0.9.0` 或 `main` 最新代码
2. `cd agent && npm install && npm run interaction:check && npm run typecheck`
3. Agent cases：`cd agent && npm run acceptance:cases`
4. E2E：`cd e2e && $env:CI='1'; $env:EVIDENCE_VERSION='v0.9.0'; npx playwright test tests/ai-form-v090.spec.ts`
5. 可选冒烟：配置 `DEEPSEEK_API_KEY` 后 `cd agent && npm run interaction:smoke`

## 依赖版本
