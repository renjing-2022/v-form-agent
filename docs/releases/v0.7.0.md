# v0.7.0 — 交互执行面第一刀：事件 shape 登记 + 澄清闭环

## 概述

v0.7.0 在 v0.6 重型容器基线上增加**平行于 refine 的事件意图管线（仅知识 + 澄清）**：登记与运行时真源对齐的事件 shape；新增 `POST /api/agent/v1/event` 多轮澄清产出 EventSpec。本版**不生成、不合入、不执行**事件 JS；合入层事件禁写与 v0.6 一致。

## 主要能力

### 事件 shape 登记

- `(type, eventKey) → params[]` 与 fieldMixin / dialog / sub-form 等真源 parity
- `writableIn=v0.8+` 预留纯前端事件；接口类（远程查询 / 上传族）为 `never`
- Catalog `forbiddenKeys` 仍含全部 `on*`；本版不合入

### `/event` 澄清闭环

- `need_clarification`：定向问题；不写事件键
- `spec_ready`：EventSpec + 可判定示例契约；`applied=false`，不写画布
- 危险 / 接口意图诚实拒绝

### 前端分流

- AiChat 交互意图走 `/event`；结构 / 属性 / formula 仍走 `/refine`
- `spec_ready` 不提供「确认写入事件代码」

## 验收

- DeliveryGuard acceptance：**passed**（15 cases）
- Playwright v0.7 专项：**3 passed**（mock-only 澄清 UI，无事件运行时断言）
- 报告：[docs/acceptance/v0.7.0.md](../acceptance/v0.7.0.md)

## 非目标（本版不含）

- 生成 / 合入事件 JS 或 `formConfig.functions`
- Playwright 真实渲染执行断言（属 v0.8）
- 网络 / DOM / `eval` / 定时器等危险能力
- 生产云模型 SLA（本版验收为 mock-only）

## 升级说明

1. 拉取 `v0.7.0` 或 `main` 最新代码
2. `cd agent && npm run catalog:sync && npm run catalog:check`
3. Agent cases：`cd agent && npm run acceptance:cases`
4. E2E：`cd e2e && $env:EVIDENCE_VERSION='v0.7.0'; npm run test:v070`（`AGENT_ALLOW_MOCK=1`）

## 依赖版本

建议在 **v0.6.0** 之上升级；v0.6 重型容器与事件禁写合入断言均保留。
