# v0.4.0 — DesignTruthGraph Catalog 2.0 + NL↔手动高精度

## 概述

v0.4.0 将组件知识从「可写键列表」升级为 **DesignTruthGraph 设计真源图**，使 generate / refine / Excel 三路径共用同一 Validator，并显著缩小自然语言与手动操作的偏差。

## 主要能力

### DesignTruthGraph（Catalog 2.0）

- 离线编译 `(scope, type, prop)` 真源：applicable、editor、valueKind、enum、inherit、linkage 等
- 多真源：`widgetsConfig` + `propertyRegister` + 219 property-editor + 渲染/联动/identity/扩展边界 policy
- 50×(type,prop) 确定性抽样 parity（`catalog:check`）

### 统一 Validator + IntentGate

- **高精度门禁**：如 `labelWidth` 须 number、`size` 枚举与编辑器一致
- **诚实 summary**：toast / 摘要绑定 merge 后机器校验，未落地高精度键 → 422
- **消灭第二真源**：addField 从 widgetsConfig 克隆；generate / Excel 与 Catalog 同源

### NL 面增强

- 口语归一（如「右对齐」→ `label-right-align`）
- **label 定位**、**parentScope**、tab 下批量 patch
- 容器级 refine 子集（tab-pane / grid-col 等）
- 属性联动（remote/filterable、multiple/defaultValue、autosize/rows 等）

### 前端契约

- `loadFormJson` 前 **`preApplyFormJsonGate`**：重复 widget.id 等结构问题前置拦截

## 升级说明

1. 拉取 `v0.4.0` 或 `main` 最新代码
2. `cd agent && npm run catalog:sync && npm run catalog:check`
3. 开发 / E2E 仍可用 `AGENT_ALLOW_MOCK=1`（不依赖 DeepSeek Key）

## 依赖版本

建议在 **v0.3.0** 之上升级；v0.3.0 的 Catalog / cssCode / 精准定位能力均保留。
