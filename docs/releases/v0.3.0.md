# v0.3.0 — Widget Catalog + 厚 P1 属性 / 受控 cssCode

## 概述

v0.3.0 在 v0.2.0 多轮优化基础上，引入 **Widget Catalog 组件知识库**，让 Agent 从 v-form 源码同步可写属性，并支持常见属性精准修改与受控 `cssCode` 样式修复。

## 主要能力

### Widget Catalog

- 以 `widgetsConfig.js` 为真源，生成/同步机器可读 Catalog
- `catalog:check` 漂移校验，规划 / 合入 / 校验共用同一份规范
- 按目标组件类型向 LLM 注入相关 Catalog 片段（非全量塞入）

### Refine 增强

- **常见属性**：Catalog 驱动的 `updateField` patch（size、placeholder、disabled 等）
- **精准定位**：表单摘要含 id / name / label / type / 路径线索；多同名控件可区分
- **受控 cssCode**：支持 `formConfig.cssCode` 与 `customClass`；危险 CSS / 超长 / 非法输入拒绝
- **文案边界**：延续 FR-6；样式类诉求走 cssCode，不误改 text 组件

### 兼容与回归

- `POST /api/agent/v1/refine` 外壳兼容 v0.2.0
- v0.2.0 P0 能力回归：结构 tab、options、公式、多轮 apply、reject 保留画布

## 升级说明

无需额外配置。开发环境照旧启动 `agent` + `v-form`；建议运行 `cd agent && npm run catalog:sync && npm run catalog:check` 确认 Catalog 与本地 v-form 一致。
