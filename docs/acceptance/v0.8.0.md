### 本版本实际交付范围（收窄声明）

v0.8 交付的是 **事件 JS 的安全写入与真实执行闸 + 少量模板化交互**：

- `/event` 的 clarify → generate(code_preview) → apply(applied/draft) 状态机；
- 事件 JS 静态护栏（网络、动态执行、DOM、定时器、未知字段）；
- 只有在真实 VFormRender 中按 examples 执行、且服务端以 `actual` 对照 `expect` 重判全部一致时才允许写入画布；
- 模板覆盖：值变更求和、值变更显隐/禁用、按钮/生命周期/子表增行写入字面量、提交前「X 不能小于/大于 N」类校验。

v0.8 **不**支持任意自然语言描述的页面交互（如 tab 下一页+校验+失败定位）。该目标由 v0.9（LLM → InteractionPlan → 确定性编译）承担。
